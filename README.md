# 庭先 / niwasaki

店舗ごとの配送・納品ノウハウをまとめ、PC・iPhone・Androidで現場利用できるようにする業務ツール。

> **現在：ベータ版開発中**

## コンセプト

**庭先はExcelではない。**

既存のExcel/PDFを取り込み、店舗情報・配送情報・写真・注意事項などを庭先の内部データとして管理する。

Excelは入力元の一つとして扱い、取り込み後は庭先の共通店舗データとして編集・保存する。

## ベータ版の現在地

現在は、実際の現場利用を想定した**Webベータ版**へ移行中。

ブラウザから利用できる構成を基本とし、PCだけでなくiPhone・Androidでも同じ庭先データを扱えるようにする。

### 現在実装済み

- 店舗一覧・検索
- ＋新規登録
- 店舗情報の編集・保存
- Excelから取込（`.xlsx` / `.xls`）
- Excel取込後の人による確認・修正
- `.niwa`店舗ファイルの書き出し / 読み込み
- 全店舗バックアップ
- 店舗単位の「この庭先を共有」
- Google Mapsへのリンク
- 複数写真の追加・削除
- 写真ごとのカテゴリ・メモ
- `.niwa`の暗号化
- Webアプリ/PWA向けの基本構成
- GitHub Pagesによるベータ公開用Workflow

### Excel取込の考え方

Excelのレイアウトは店舗・ファイルによって異なるため、固定セルだけに依存しない。

取り込み時は、

**Excel解析 → 自動推定 → 人が確認・修正 → 保存**

の順で処理する。

自動推定した値を正式データとして扱わず、最終確定は必ず人が行う。

Excelに埋め込まれた画像も、対応可能な形式では庭先の写真候補として取り込む。

## 対応環境

- Windows PC
- iPhone
- Android

Webブラウザを基本とし、将来的にはMac/iPadも対象にする。

## `.niwa`について

`.niwa`は庭先専用のポータブルファイル。

店舗単位で共有する場合は、

`庭先_店舗名.niwa`

のように1店舗分をまとめて扱える。

写真を含む店舗データを一つのファイルとして受け渡せる構成にする。

現在のベータ版では、ユーザーがパスワードを入力する方式ではなく、庭先側で暗号化・復号・検証するローカル用途の方式を採用している。

※これは本格的なユーザー認証・権限管理を代替するものではない。将来のサーバー版では認証・権限・鍵管理を追加する。

## 初期ゴール

1. 新規店舗を作成する
2. Excelから既存店舗を取り込む
3. 人が内容を確認・修正する
4. 庭先として保存する
5. 店舗単位の`.niwa`として共有する
6. PC・iPhone・Androidで開いて利用する

## Webベータ版

GitHub Pagesでの公開を前提として、ブラウザからURLを開くだけで利用できる形へ移行している。

公開先はGitHubリポジトリのPages設定に依存するため、Pagesを有効化した環境でベータ版URLを利用する。

## データ管理

実際の会社データはこのリポジトリに保存しない。

このリポジトリにはコード・設計書・テスト等を保存し、顧客情報、電話番号、住所、写真、`.niwa`などの実データはGit管理対象外とする。
