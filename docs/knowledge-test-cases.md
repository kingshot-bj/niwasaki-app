# niwasaki. 実データベース検証ケース

このドキュメントは `niwasaki-knowledge` の旧庭先整理データを元にした、本体の初期受け入れテスト。

## TC-001 店舗詳細：SGキャリア
- 店舗名が表示される
- コースが表示される
- 納品場所、搬入口、駐車場所、時間制限、注意事項が表示される
- 作業手順タブで手順が順番に表示される
- 出典タブで元資料名を確認できる
- お気に入り切替が動作する

## TC-002 コース：三郷汎用2コース
- コース検索に表示される
- 5店舗がコースに紐付いている
- コースから店舗一覧へ遷移できる
- 店舗を選択して詳細へ遷移できる

## TC-003 店舗：ワイズ ペリエ西小中台店
- 搬入口、駐車、デリカ、台車に関する配送情報を表示できる

## TC-004 店舗：ワイズ ペリエ西千葉店
- 守衛室、入館証、搬入口、台車など複数の手順を表示できる

## TC-005 共通マニュアル
- 三郷汎用2コース画面から共通マニュアルの存在を確認できる
- レオックマニュアルの版と出典を表示できる

## TC-006 未登録項目
- コード・住所・電話番号などが未登録でも画面が壊れない
- 「住所未登録」「—」などで安全に表示される

## TC-007 データ編集
- 店舗詳細から情報変更へ進める
- 保存後もデータが保持される
- 新規店舗登録ができる
